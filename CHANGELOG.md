# Changelog

All notable changes to Zestimonial are documented here.

## [0.1.0] - 2026-10-16

First public release.

### Added
- Public collection form with star rating, role and consent, plus personal email requests through Resend.
- Automatic follow-up reminders after 3 and 7 days, run by a daily Vercel cron job.
- Review inbox to approve or reject responses.
- AI highlights and topic tags from Claude. Highlights are checked to be verbatim before they are saved.
- Six embeddable widget layouts (carousel, grid, masonry, marquee, single card, rating badge) with accent colour, corner radius, item limit and tag filter, plus a one-line `embed.js` script.
- Public Wall of Love page with a custom headline.
- Export studio with Instagram (1080 × 1080), LinkedIn/X (1200 × 630) and Story (1080 × 1920) images, and print-ready cards that save as PDF.
- Dashboard with sidebar shell, command palette, notifications and dark mode.
- Supabase schema with row level security and two migrations.
- README with banner, workflow and feature graphics, badges and setup guide.
- LinkedIn launch graphics in `docs/linkedin/`.
